# 구현 및 검증 현황

기획안에 맞춰 폴더만 생성한 상태가 아니라, 시뮬레이터와 비교 실험을 실행할 수 있는 구현 및 초기 연구 결과를 완성했습니다. 아래는 기획안의 6주 작업 항목별 현황이며 실제 6주가 경과했다는 뜻은 아닙니다.

| 기획 단계 | 구현·검증 내용 | 현황 |
|---|---|---|
| 1주: 환경·기본 탐색 | 4방향 Grid, 비용 1·3·5, 6개 고정 방법, 독립 Bellman-Ford로 최적 비용 비교 | 완료 |
| 2주: 예산·중단/재개 | 공통 확장·시간 예산, 독립 탐색 상태, 재개 일치 검증, 중복 확장 차감 | 완료 |
| 3주: 제어기 | 초기 선택, 실제 진행 관찰, 최대 2회 전환, incumbent 보존, 이유 기록 | 완료 |
| 4주: 기준선·규칙 고정 | ARA*, 4개 규칙 후보, 별도 검증 선정, 고정 기준선 weighted_1.5 | 완료 |
| 5주: 평가·제거 실험 | 확장 예산 32,400회, 시간 제한 4,050회, 지도 단위 신뢰구간·조건별 비교 | 완료 |
| 6주: 시연·보고서 | 한국어 웹 화면, 탐색 재생·지도 편집·결과 저장, SVG·CSV·Markdown·HTML 보고서 | 구현 완료 |

## 검증 증거

- Python `unittest` 20개 통과. 작은 격자의 모든 장애물 조합, 독립 최적 비용 oracle, 가중 지형, 중단/재개, 예산 0·1·7·32·99, 실패 상태 구분, ARA* 최적성·개선 단조성 등을 포함합니다.
- JavaScript 문법 검사 통과. `node tests/frontend_smoke.cjs`에서 로컬 API 연결, 초기 지도, 비교 결과, 재생, 장애물 편집, U자 지도 실행을 최소 DOM으로 검증했습니다.
- 실제 HTTP 요청에서 가중 미로 경로 반환 및 100×100 지도의 예산 100 준수를 확인했습니다.
- `scripts/verify_results.py`에서 개발 540회·검증 1,080회·최종 확장 32,400회·최종 시간 4,050회, 합계 38,070개의 저장 결과를 검사했습니다. dev·validation·test map_id가 겹치지 않으며 경로 개선 비용은 단조 감소하고 적응형 전환은 최대 2회입니다.
- `results/smoke`의 480회 작은 실험은 실제 Python allocation peak를 추가 계측했습니다. 본 평가의 메모리 지표는 보존 상태 추정치입니다.

연결된 브라우저가 없는 환경이므로 실제 브라우저 렌더링의 시각 검사는 수행하지 못했습니다. 기능 검증과 화면 스크립트 검증은 완료했으며, `python run.py demo`로 실제 화면을 열어 확인할 수 있습니다.

## 연구 결과

현재 규칙의 전체 S1.10은 검증에서 선정한 고정 Weighted A*(1.5)보다 낮았습니다. 일부 작은 가중 지도에서는 적응형이 유리했지만, 큰 지도와 우회 구조에서 전환과 중복 탐색이 불리하게 작용했습니다. 결과를 보고 test 지도에 맞춰 규칙을 다시 조정하지 않았습니다.

[초기 연구 보고서](INITIAL_REPORT.md), [전체 확장 예산 보고서](../results/study/evaluation/report.md), [시간 제한 보고서](../results/study/time_evaluation/report.md)를 참고하세요.

후속 연구는 별도의 새로운 개발·검증 지도에서 전환의 기대 이득·잔여 예산 판단을 보완하고, 시간 실험 반복과 프로세스 RSS 계측을 추가하는 방향이 적절합니다. 학습 기반 선택기와 탐색 상태 공유는 기획안대로 확장 기능으로 남겨두었습니다.
