**프로젝트 기획안: 계산 예산과 탐색 진행 상황을 고려하는 합리적 경로 탐색 에이전트**

**프로젝트명:** Budget-Aware Pathfinding Agent  
**핵심 주제:** 제한된 계산 자원에서 탐색 전략의 선택·전환·종료가 목표 도달률과 경로 품질에 미치는 영향

**1. 프로젝트 개요**

본 프로젝트는 격자 환경에서 경로를 탐색하는 에이전트를 구현하고, 계산 예산에 따라 어떤 탐색 행동이 합리적인지 실험한다.

에이전트는 지도 크기와 장애물 밀도에 따라 초기 알고리즘을 선택한다. 탐색 중에는 남은 예산과 진행 상황을 관찰하여 현재 전략을 유지하거나 다른 전략으로 전환한다. 경로를 발견한 뒤에는 추가 탐색으로 품질을 개선할지, 현재 경로를 반환할지 결정한다.

교재의 Acting Rationally와 Limited Rationality를 다음 문제로 구체화한다.

> 최적 경로를 찾는 데 계산을 계속 사용하는 것과, 현재 확보한 경로를 반환하는 것 중 어느 행동이 주어진 자원 제약에서 더 유리한가?

**2. 선행 프로젝트와의 차별성**

| 선행 사례 | 주요 내용 | 본 프로젝트의 차별화 방향 |
|---|---|---|
| [PathPlanning](https://github.com/zhm-real/PathPlanning) | 다양한 탐색 알고리즘 구현과 애니메이션 | 알고리즘 위에 자원 배분을 결정하는 제어 에이전트를 구현 |
| [Pathfinding-Resource-Comparison](https://github.com/jamesc91/Pathfinding-Resource-Comparison) | 시간·메모리·탐색 노드·경로 길이 비교 | 자원 사용량을 측정하면서 전략 선택의 효과까지 검증 |
| [실시간 탐색 알고리즘 선택 연구, 2017](https://ojs.aaai.org/index.php/AIIDE/article/view/12927) | 지도에 따라 사용할 탐색 알고리즘을 분류기로 선택 | 지도 특성과 함께 남은 예산·실행 중 진행 정보를 사용 |
| [ARA*, 2003](https://papers.nips.cc/paper_files/paper/2003/hash/ee8fe9093fbbb687bef15a38facc44d2-Abstract.html) | 초기 해를 빠르게 구하고 기존 탐색을 재사용하여 점진적으로 개선 | 여러 전략에 예산을 배분하는 방식과 단일 anytime 탐색을 비교 |
| [Anytime Planning의 메타추론 연구, 2022](https://ojs.aaai.org/index.php/ICAPS/article/view/19842) | 탐색 매개변수와 종료 시점을 실행 중 조절 | 설명 가능한 규칙 기반 제어와 전환 비용을 포함한 격자 실험에 집중 |

본 프로젝트의 기여는 다음 세 가지로 설정한다.

- **전환의 실익 검증:** 전략을 바꾸어 얻는 이득이 중복 탐색과 제어 비용을 상쇄하는지 측정한다.
- **환경 구조에 따른 분석:** 장애물 밀도가 같아도 배치 구조가 달라지면 적응형 전략의 효과가 달라지는지 확인한다.
- **실패를 포함한 품질 평가:** 경로를 찾은 사례의 평균 품질뿐 아니라, 제한 안에 일정 품질 이상의 경로를 확보한 비율을 평가한다.

이는 선행 연구를 바탕으로 한 구현·실험상의 차별점이며, 학술적 최초성을 주장하지 않는다.

**3. 연구 질문과 가설**

| 연구 질문 | 검증할 가설 |
|---|---|
| 예산에 따른 초기 전략 선택이 유용한가? | 여러 조건을 합친 평가에서 초기 선택 에이전트가 가장 좋은 단일 고정 전략보다 높은 목표 도달률을 보일 수 있다. |
| 탐색 중 전략 전환이 추가 이득을 주는가? | 초기 선택이 부적절했던 지도에서는 진행 정보를 활용한 전환이 성능을 개선할 수 있다. |
| 적응을 위한 계산도 가치가 있는가? | 작은 예산에서는 제어·전환 비용 때문에 적응형 에이전트가 불리할 수 있다. |
| 장애물 밀도만으로 전략을 선택할 수 있는가? | 같은 밀도에서도 막다른 길과 우회 구조에 따라 유리한 전략이 달라진다. |

가설을 확인하는 것뿐 아니라, 성립하지 않는 조건을 찾는 것도 연구 결과로 인정한다.

**4. 구현 환경과 알고리즘**

환경은 전체 지도가 주어진 정적 Grid World로 한정한다. 에이전트는 상하좌우로 이동하며, 출발점과 도착점은 서로 다른 통과 가능한 칸으로 설정한다.

두 종류의 이동 비용을 사용한다.

- **균일 비용 환경:** 모든 이동 비용이 1.
- **가중 비용 환경:** 지형에 따라 이동 비용이 1, 3, 5.

기본 구현 알고리즘은 BFS, Dijkstra, A*, Greedy Best-First, Weighted A*이다. Weighted A*는 우선 가중치 1.5와 3.0을 사용하고 검증 단계에서 조정한다.

A*의 휴리스틱은 맨해튼 거리에 최소 이동 비용을 곱해 구성한다. 더 좋은 경로를 발견했을 때 비용과 우선순위를 갱신하도록 구현한다. BFS는 균일 비용 환경의 최단 경로 기준으로 사용하고, 가중 비용 환경에서는 최저 비용을 보장하는 알고리즘으로 해석하지 않는다.

**5. 적응형 에이전트 설계**

에이전트를 경로 탐색을 수행하는 탐색기와, 탐색기에 자원을 배분하는 제어기로 구성한다.

| 관찰 정보 | 사용 목적 |
|---|---|
| 지도 크기, 장애물 밀도, 출발–도착 거리 | 초기 전략 선택 |
| 남은 확장 예산, 경과 시간 | 추가 탐색 가능 여부 판단 |
| 최근 구간의 휴리스틱 감소량 | 목표 방향으로 탐색이 진행되는지 관찰 |
| frontier 크기와 증가량 | 탐색 후보가 얼마나 늘어나는지 관찰 |
| 현재 확보한 경로 비용 | 개선 탐색과 종료 판단 |
| 이전 전략 전환 횟수 | 잦은 전환 제한 |

제어기는 다음 세 행동을 선택한다.

| 행동 | 의미 |
|---|---|
| 유지 | 현재 탐색기에 다음 계산 구간을 배정 |
| 전환 | 다른 탐색기를 시작하거나 중단했던 탐색기를 재개 |
| 반환 | 확보한 경로 중 비용이 가장 낮은 경로를 반환 |

아직 경로가 없다면 종료 시 “예산 내 경로 미발견”을 반환한다. 이를 “경로가 존재하지 않음”과 구분한다.

초기 구현은 규칙 기반으로 진행한다. 예를 들어 진행 정체가 여러 관찰 구간에서 이어질 때만 전환을 허용하고, 전환 횟수는 최대 2회로 제한한다. 이 규칙과 임계값은 개발·검증 지도에서 조정하고 최종 평가 전에 고정한다.

각 탐색기는 자신의 frontier와 방문 정보를 보관한다. 처음 사용하는 전략은 출발점에서 시작하고, 재개하는 전략은 자신의 이전 상태를 이어간다. 서로 다른 알고리즘 사이의 탐색 상태 공유는 확장 기능으로 남긴다.

**중복 탐색한 노드도 전체 예산에서 차감한다.** 여러 탐색기를 보관하는 데 필요한 메모리도 기록한다.

경로 확보 후에는 다른 탐색기를 이용해 더 저렴한 경로를 찾을 수 있다. 그동안 기존 경로를 보관하므로, 예산이 소진되어도 확보한 최선의 경로를 반환한다.

**6. 종료 판단과 합리성의 정의**

합리성을 “항상 최단 경로를 반환하는 능력” 대신 다음 성과로 평가한다.

> 주어진 자원 안에서 목표에 도달할 수 있는 경로를 확보하고, 허용 가능한 경로 품질을 달성하는 능력.

실행 중 에이전트에게 실제 최적 경로 비용을 제공하지 않는다. 최적 비용은 실험 평가에만 사용한다.

초기 휴리스틱 값 \(h_0\)는 최적 비용의 하한으로 사용할 수 있다. 현재 경로 비용이 \(C\)이고 허용 품질 비율이 \(\rho\)일 때,

\[
C \leq \rho h_0
\]

를 만족하면 허용 품질을 확보한 것으로 판단해 반환할 수 있다. 이 조건은 보수적인 충분조건이다. 만족하지 않는다고 해서 경로 품질이 나쁘다고 단정하지 않는다.

나머지 경우에는 남은 예산과 최근 경로 개선 여부를 기준으로 계속 탐색하거나 반환한다. 종료 규칙의 효과는 “첫 경로 발견 즉시 반환” 및 “항상 예산 끝까지 탐색”과 비교한다.

**7. 실험 설계**

먼저 원래 제안한 조건을 유지한다.

| 변수 | 설정 |
|---|---|
| 지도 크기 | 20×20, 50×50, 100×100 |
| 장애물 비율 | 10%, 20%, 30% |
| 노드 확장 예산 | 100, 1,000, 10,000 |
| 반복 | 조건별 서로 다른 지도 30개 |
| 기본 지도 | 무작위 장애물 배치 |

기본 평가는 27개 조건, 총 810개의 지도–예산 조합으로 구성한다. 같은 지도를 모든 알고리즘에 제공하여 결과를 짝지어 비교한다.

추가로 다음 구조를 가진 지도를 평가한다.

- 목표 방향을 따라가면 막히는 U자형 장애물.
- 큰 우회가 필요한 벽과 좁은 통로.
- 여러 막다른 길을 포함한 미로.

구조별 지도에서는 실제 장애물 밀도를 함께 기록한다. 이를 통해 밀도와 지도 구조의 영향을 구분한다.

개발·검증·최종 평가 지도는 지도 단위로 분리한다. 같은 지도의 다른 예산 실행도 같은 분할에 배치한다.

노드 확장 예산 실험과 별도로 실제 시간 제한 실험을 수행한다. 시간 예산은 예비 실험으로 적절한 수준을 정한 뒤 고정한다. **실제 시간 측정에는 특징 계산, 전략 선택, 초기화, 전환, 경로 복원 시간을 모두 포함한다.** 화면 애니메이션은 성능 측정에서 제외한다.

**8. 비교 대상과 평가 지표**

비교 대상은 다음과 같다.

| 비교 대상 | 확인할 내용 |
|---|---|
| 각 고정 알고리즘 | 기본 성능 |
| 검증 데이터에서 선정한 가장 좋은 단일 고정 전략 | 강한 기준선 대비 개선 |
| 초기 선택만 수행하는 에이전트 | 실행 중 적응의 추가 효과 |
| 전략에 예산을 균등 배분하는 방식 | 정교한 선택 규칙의 효과 |
| 제안한 적응형 에이전트 | 선택·전환·종료를 결합한 성능 |
| ARA* | 기존 anytime 탐색 대비 효과 |

기본 지표는 목표 도달률, 경로 비용, 노드 확장 수, 전체 계산 시간, 최대 메모리 사용량이다. 추가로 전략 전환 횟수, 제어 시간 비율, 첫 경로 확보 시점, 경로 비용의 개선 기록을 수집한다.

경로 품질은 다음과 같이 계산한다.

\[
\text{Path Quality Ratio}=\frac{C}{C^*}
\]

여기서 \(C^*\)는 예산 제한 없이 실행한 Dijkstra로 구한다.

핵심 종합 지표는 **품질 기준을 만족하는 도달률**이다.

\[
S_{\rho}
=
\frac{\text{예산 내 경로를 찾고 }C/C^*\leq\rho\text{인 문제 수}}
{\text{경로가 존재하는 전체 문제 수}}
\]

\(\rho\)는 1.05, 1.10, 1.25로 설정한다. 이 지표에는 제한 내 경로를 찾지 못한 사례도 실패로 포함된다.

경로 품질 평균은 성공률과 함께 제시하고, 두 방법이 모두 성공한 문제에서의 품질 비교도 별도로 보고한다. 경로가 없는 지도는 별도 집계하며, 발견 실패와 혼합하지 않는다.

**9. 차별점을 검증하는 추가 실험**

다음 기능을 하나씩 제거해 성능 변화를 확인한다.

- 진행 정보를 제거하고 지도 특성만 사용.
- 전략 전환을 금지.
- 조기 반환을 금지.
- 전환 횟수 제한을 제거.

또한 제어 비용을 제외한 시간과 포함한 시간을 함께 분석한다. 최종 성능 주장은 비용을 포함한 결과를 기준으로 한다.

결과는 전체 평균뿐 아니라 예산·지도 크기·구조별로 제시하고, 지도 단위 재표집으로 신뢰구간을 계산한다. 적응형 에이전트가 유리한 조건과 불리한 조건을 모두 보고한다.

**10. 화면과 최종 산출물**

시뮬레이터에는 지도, 현재 경로, 탐색한 칸과 함께 다음 정보를 표시한다.

- 현재 탐색 전략과 남은 예산.
- 현재 확보한 경로 비용.
- 전략 선택·전환·종료 이유.
- 시간에 따른 경로 비용 변화.
- 같은 지도에서 고정 전략과 비교한 결과.

설명은 제어기가 실제 사용한 관찰값과 규칙에서 생성한다. 예를 들어 “최근 두 구간에서 진행이 정체되어 전략 전환”과 같이 표시한다.

최종 산출물은 실행 가능한 시뮬레이터, 재현 가능한 실험 실행기, 지도와 난수 시드, 실험 결과 파일, 분석 그래프, 보고서로 구성한다.

| 6주 | 시뮬레이터 정리와 보고서 | 시연 및 제출 가능한 산출물 완성 |

학습 기반 선택기와 탐색 상태 공유는 확장 기능으로 둔다. 핵심 범위는 규칙 기반 적응형 에이전트와 공정한 비교 실험으로 완성한다.

**12. 기대하는 연구 결과**

본 프로젝트는 적응형 에이전트의 우수성을 미리 결론짓지 않는다. 다음 결과를 밝혀내는 것을 목표로 한다.

- 어느 예산과 지도 구조에서 전략 전환이 효과적인가.
- 어느 조건에서는 하나의 전략을 유지하는 편이 유리한가.
- 추가 탐색이 주는 경로 개선이 계산 비용에 비해 충분한가.
- 간단한 설명 가능한 제어 규칙으로 어느 수준의 성능을 얻을 수 있는가.

보고서의 중심 주장은 다음과 같이 설정한다.

> 제한된 자원에서 합리적인 경로 탐색은 경로의 최적성뿐 아니라, 탐색 전략을 선택하고 변경하는 비용까지 고려해야 한다. 본 프로젝트는 그 선택이 유리해지는 조건을 실험적으로 규명한다.
